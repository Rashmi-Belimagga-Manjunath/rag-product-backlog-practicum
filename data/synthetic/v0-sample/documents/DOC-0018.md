# Push Relay delivery failure runbook

Component: Push Relay (COMP-B-01) | Type: third_party | Owner: Vendor Team | Last reviewed: 2026-07-30

Third-party push notification relay. Delivery is not guaranteed by our SLA.

## Procedure

1. Check relay status page for an active incident.
2. Confirm the tenant's device token is still valid in the config store.
3. If the relay is degraded, fall back to in-app messaging.
4. Record the incident window for the weekly reliability review.
