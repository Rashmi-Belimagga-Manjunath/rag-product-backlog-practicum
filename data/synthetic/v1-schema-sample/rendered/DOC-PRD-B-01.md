# Tally streak retention

Document: DOC-PRD-B-01
Status: current. Version 1.0. Last modified 2026-06-15.

Author: Founder
Product: Tally (PROD-B)

## Background

Covers reducing user churn when an established streak is about to break.

## Goals

Reduce the number of steps a new employee must complete before they can reach a working product, while keeping every mandatory compliance step enforced.

## Non-goals

This document does not cover manager approval workflows or payroll export formatting. Those are specified separately.

## Requirements

### REQ-B-01: Streak loss is mitigated before it occurs

The product must offer a reduced-effort alternative before a user breaks an established streak.

This requirement is normative for Tally. Where another document disagrees, this statement takes precedence.

## Success measures

Measured as: completion rate of the compliance steps, time to first productive action, and support contact volume in the first week.

## Open questions

How many days should elapse before the tax step is requested? The current answer of three days is provisional.
