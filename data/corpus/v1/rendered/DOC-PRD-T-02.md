# Tally template adoption and reminders

Document: DOC-PRD-T-02
Status: SUPERSEDED. Version 1.0, last modified 2026-02-02. This version was replaced by DOC-PRD-T-02-v2 and is retained for history only. Do not implement from this document.

Author: Founder
Product: Tally (PROD-T)

## Background

Covers one-step template adoption and user-configurable reminder schedules.

## Goals

Reduce the friction between signing up and keeping a first habit going, while keeping the streak mechanic predictable and honest for every user.

## Non-goals

This document does not cover habit template curation or social features. Those are specified separately.

## Requirements

### REQ-T-02: Templates are adoptable in one step

A user must be able to adopt a habit template without entering the habits it contains by hand.

This requirement is normative for Tally. Where another document disagrees, this statement takes precedence.

### REQ-T-03: Reminders respect a schedule

Reminder schedules must be user-configurable and must not exceed one prompt per habit per day.

This requirement is normative for Tally. Where another document disagrees, this statement takes precedence.

## Success measures

Measured as: thirty-day streak survival, share of recovery prompts accepted, and repeat-week retention after a prompt is offered.

## Open questions

How forceful should the first recovery prompt be? The current answer of a single light suggestion is provisional.
